# Telegram Бот ИИ-офиса ООО "СТРОЙСТАНДАРТ"

## Описание
Рабочий Telegram бот с интеграцией DeepSeek AI для:
- Анализа договоров и рисков
- Составления писем, претензий, жалоб (в ФАС, суд)
- Поиска судебных прецедентов
- Консультаций по 44-ФЗ, 223-ФЗ, ГК РФ
- Генерации документов (.docx)

## Установка зависимостей
```bash
pip install python-telegram-bot aiohttp python-docx
```

## Настройка переменных окружения
Скопируйте `.env.example` в `.env` и заполните:
```bash
TELEGRAM_BOT_TOKEN=ваш_токен_бота
DEEPSEEK_API_KEY=ваш_api_ключ_deepseek
```

## Запуск бота
```bash
python run_bot.py
```

## Структура
- `src/bot/telegram_app.py` - основной код бота
- `src/core/document_generator.py` - генерация документов
- `run_bot.py` - точка входа

## Функционал
1. **Текстовые сообщения** - анализ через DeepSeek AI
2. **Документы** - загрузка и подготовка к анализу
3. **Генерация файлов** - автоматическое создание .docx документов

## Примечания
- Без `TELEGRAM_BOT_TOKEN` бот не запустится
- Без `DEEPSEEK_API_KEY` бот работает без AI (только базовые функции)
