## 🤗 Проверка интеграции с ИИ (опционально)

### 8. Установка Ollama (для Windows)
1. Скачать с https://ollama.ai
2. Установить: `ollama setup`
3. Загрузить модель: `ollama pull llama3.1`
4. Проверить: `ollama list`

### 9. Настройка в приложении
1. Открыть "Настройки" → "Локальный ИИ"
2. URL: `http://127.0.0.1:11434`
3. Модель: `llama3.1`
4. Нажать "Проверить подключение"
5. Статус: "Подключено" ✅

### 10. Тест анализа работы
1. Выбрать работу в ВОР
2. Нажать "Анализ ИИ"
3. Проверить JSON-ответ:
   - Тип работы
   - Скрытая/открытая
   - Необходимые документы
   - Нормативные документы

## 🐛 Отладка проблем

### Ошибка: "QAction cannot be imported"
**Решение:** QAction должен импортироваться из `QtGui`, а не `QtWidgets`

### Ошибка: "DatabaseManager.__new__() takes 1 positional argument"
**Решение:** Использовать `DatabaseManager.get_instance()` вместо конструктора

### Ошибка: "libEGL.so.1: cannot open shared object file"
**Решение (Linux):** `apt-get install libegl1-mesa libxcb-xinerama0`

### Ошибка: "No module named 'PySide6'"
**Решение:** `pip install PySide6`
